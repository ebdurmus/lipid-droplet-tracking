# Lipid Droplet Detection and Tracking in Python

A reproducible Python workflow for detecting, tracking,
and analyzing lipid droplet dynamics in fluorescence microscopy.

## Objectives

- Detect lipid droplets in microscopy images.
- Track lipid droplets across consecutive frames.
- Quantify lipid droplet mobility using mean-squared displacement (MSD).
- Compare Python-based tracking results with TrackMate.

## Dataset

Initial development uses synthetic microscopy images
and simulated TrackMate-style tracking data.
